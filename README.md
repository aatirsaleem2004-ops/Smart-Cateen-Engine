# Canteen Billing System (Dart)
A simple console-based canteen billing system built in Dart. Applies VIP/wallet-based discount and calculates the final bill for a sample order.
Features
Student profile (name, roll number, wallet balance, VIP status)
Discount logic based on VIP status or wallet balance
Canteen menu displayed using a `Map`
Order total calculated from a `List` of ordered items
Final bill calculated after applying discount
Tech Used
Dart
How to Run
```bash
dart run main.dart
```
Or run directly in DartPad.
Sample Output
```
Student: Aatir
Roll Number: 62
Discount applied: 20%

--- Order Summary ---
Items Ordered: [Burger, Juice]
Total (before discount): Rs. 350.0
Total Bill: Rs. 280.0
```
Concepts Used
Variables & Data Types
If-Else Conditions
List and Map
Loops
String Interpolation
